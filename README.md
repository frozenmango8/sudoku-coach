# Sudoku Coach

A Sudoku pad that explains the next deduction instead of filling in the digit.

https://frozenmango8.github.io/sudoku-coach/

![A medium puzzle with a naked-pair hint](screenshot.png)

Techniques: naked single, hidden single, naked pair, hidden pair, naked triple, hidden triple, pointing pair, box-line reduction, X-wing.

```
npm install
npm run dev
```

Open the URL Vite prints. The app is served under `/sudoku-coach/`.
